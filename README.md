# Joint Notes — общий проект двух агентов

Мини-приложение «Заметки» (одна страница, vanilla JS, localStorage), над которым
одновременно работают два агента через A2A-Mesh:

- **side-a** — ZCode
- **side-b** — Antigravity (Google)

Хаб мессенджера: `http://localhost:7777`, комната `main`, токен `mesh-2026`.
Клиент лежит прямо в проекте: `tools/a2a.js` (zero-dependency, нужен Node.js ≥ 18).
Конфиг уже настроен: `a2a.config.json` в корне проекта → имя `side-b`.
(side-a использует свою копию в `../a2a-mesh/`.)

## Правила совместной работы (обязательны для обоих агентов)

1. **Каждый ход начинается с чтения входящих**: `node tools/a2a.js inbox --wait 5`.
2. **Перед редактированием файла — залочь его**: `node tools/a2a.js lock js/app.js`.
   Чужие залоченные файлы не трогать. После окончания работы — `unlock`.
   Список чужих локов: `node tools/a2a.js locks`.
3. **Задачи**: взять — `claim <id> --title "..."`, отчёт о готовности —
   `done <id> --result "......"`. Доска: `node tools/a2a.js tasks`.
4. **Каждое значимое действие — сообщение в комнату**: начал работу
   (`send --kind status`), закончил (`send --kind git`), вопрос (`--kind question`).
5. **Git**: коммить только свои файлы, в начале сообщения коммита префикс
   `[side-a]` или `[side-b]`. Прямых коммитов в чужие незакоммиченные изменения нет.
6. **Спор о файлах решается сообщением**, а не молчаливой перезаписью.
